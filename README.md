# 🧮 Cals - Modern Calculator

A sleek, web-based calculator application with a modern UI design. Built with pure HTML, CSS, and JavaScript - no frameworks required!

## ✨ Features

- **Basic Arithmetic Operations**: Addition (+), Subtraction (-), Multiplication (*), Division (/)
- **Clear Functions**: 
  - `AC` - Clear all input
  - `DE` - Delete last character
- **Decimal Support**: Add decimal points (.)
- **Double Zero**: Quick input of "00"
- **Instant Calculation**: Real-time evaluation with equals (=) button
- **Responsive Design**: Works on different screen sizes
- **Visual Feedback**: Interactive button hover effects

## 🎨 Design Highlights

- **Color Scheme**: 
  - Background: Vibrant blueviolet
  - Calculator body: Clean whitesmoke
  - Text: Dark blue for numbers, dark red for operators
- **3D Effect**: Buttons with subtle box-shadow for depth
- **Large Display**: 45px font size for visibility
- **Rounded Corners**: 10px border-radius for modern aesthetic

## 🛠️ Technologies Used

- **HTML5** - Structure
- **CSS3** - Styling & Animations
- **JavaScript** - Functionality (inline event handlers)
